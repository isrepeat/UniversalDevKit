# AndroidAppPreviewer Plugin SDK

NuGet UniversalDevKit.AndroidAppPreviewer.PluginSDK использует корневую Version.json. Публичные заголовки находятся в Includes/Windows/AndroidAppPreviewerPluginSdk, native-реализация и managed ABI — в Sources/Windows/AndroidAppPreviewerPluginSdk. Единственный native-экспорт xp_get_abi сохраняет C ABI версии 1.

Native-компонент описан в [Projects/Components/AndroidAppPreviewerPluginSdk.json](../../../Projects/Components/AndroidAppPreviewerPluginSdk.json) и включён в Components.json. Здесь перечислены все C++ файлы и зависимости от XamlRuntime.Static, OpenGLESRenderer.Static и Diagnostic.Dynamic. Генератор создаёт Shared vcxitems, Static и Dynamic проекты в Projects/MsBuild/AndroidAppPreviewerPluginSdk. Публичные заголовки видны в фильтре Public, реализация — в Internal и Session.

C#-проект [AndroidAppPreviewerPluginSdk.Managed](../../../Projects/MsBuild/AndroidAppPreviewerPluginSdk.Managed/AndroidAppPreviewerPluginSdk.Managed.csproj) содержит только NativeRuntime.cs из Sources/Windows/AndroidAppPreviewerPluginSdk/Managed. Имя поставляемой сборки AndroidAppPreviewer.PluginSDK.dll сохранено. NuGet объединяет обе части; состав native-поставки и список компилируемых файлов читаются из того же описания компонента, без GLOB по каталогам.

Сборка: `Scripts/Packages/Windows/Pack.AndroidAppPreviewerPluginSdk.cmd`. ANGLE готовится закреплённым рецептом UDK через vcpkg и binary cache. SDK включает Debug/Release x64, CRT MD/MDd: установленные CMake-пакеты XamlRuntime.Static, OpenGLESRenderer.Static, Helpers и Diagnostic.Dynamic; ANGLE и лицензии; исходники SDK; managed AndroidAppPreviewer.PluginSDK.dll для net8.0.

AndroidTemplates восстанавливает SDK версии UdkVersion в Build/Preview/sdk-<version>. CMake-конфигурация AndroidAppPreviewerPluginConfig.cmake предоставляет AndroidAppPreviewerPlugin::SDK и android_app_previewer_add_runtime(target); функция добавляет реализацию в прикладной плагин и копирует runtime DLL рядом с ним. Прикладной PreviewSession реализует ApplicationPreviewSession. Объект session::PluginDefinition регистрирует фабрику сессии и поставщик JSON-описания; native-компонент собирается отдельно без неопределённых прикладных символов. Бизнес-логика остаётся в проекте потребителя. Новый шаблон и SDK нужно обновлять вместе; внешний C ABI xp_get_abi версии 1 не изменился.
