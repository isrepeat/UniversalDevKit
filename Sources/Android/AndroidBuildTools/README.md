# AndroidBuildTools

PowerShell, потребительские CMake-модули, исходники Gradle-плагинов и реализация ApplicationFramework находятся здесь. Публичные C++ заголовки — в Includes/Android/AndroidBuildTools. Проекты сборки — в Projects/Gradle/Library/AndroidBuildTools и Projects/Cmake/Library/AndroidBuildTools.

[Описание поставки](../../../Packages/Android/AndroidBuildTools/README.md). Delivery собирает из этих каталогов tools, cmake, gradle и платформенные публичные заголовки в build/native/include внутри NuGet.
