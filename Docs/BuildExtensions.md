# Сборочные расширения компонентов

Необязательный объект buildExtensions в описании компонента содержит пути от корня репозитория: cmake (.cmake), msbuildProps (.props), msbuildTargets (.targets). Допустимы существующие файлы внутри Projects; неизвестные ключи отклоняются. Обычные компоненты не требуют расширений.

MSBuild импортирует props после публичных настроек, перед списком исходников; targets — в конце Shared.vcxitems. Это действует и для библиотек, и для Shared-consumer. Расширение использует уникальные имена с префиксом __UniversalDevKit и именем компонента, не меняет настройки соседних проектов. IntDir принадлежит текущему consumer либо изолированной сборке библиотеки. Генерируемые элементы добавляются расширением, а не обычным списком существующих файлов JSON.

CMake вызывает функцию udk_extend_<имя компонента>(target variant outputRoot) после настройки каждого Static/Dynamic target, до связывания межкомпонентных зависимостей и экспорта. outputRoot расположен внутри binary directory и разделён по компоненту и варианту. Расширение добавляет custom commands с явными входами, выходами и зависимостями, исходники и include-пути указанному target. Это доверенный код сборки, а не изолированная песочница. Оно не должно изменять глобальные настройки или другие компоненты. Прежние Projects/Cmake/<компонент>/CMakeLists.txt остаются совместимыми.

Публичный путь результата содержит Generated: UniversalDevKit/<компонент>/Generated/<файл>.h. Выходы не записываются в Sources/Includes и не коммитятся. Генерируемые публичные заголовки устанавливаются расширением с тем же include-путём; consumer бинарного пакета не запускает генератор. Для MSBuild-библиотеки публичные генерируемые include-пути требуют отдельной передачи consumer: ProjectReference автоматически их не передаёт. Первый fixture проверяет Shared MSBuild и установленный CMake-пакет.

Host-инструмент исполняется на машине сборки независимо от target toolchain. Первый fixture использует явно выбранный host CMake: UniversalDevKitHostCMake для MSBuild, CMAKE_COMMAND для CMake. Загрузка инструментов, внешние пакеты и собственный язык схем не вводятся.

Пример находится в Tests/Fixtures/Libraries/Generated. Его вход Input.txt содержит число; Generate.cmake создаёт Value.h и Value.cpp. Проверки запускаются через Tests/Infrastructure/TestBuildExtensions.ps1. Общий запуск RunTests пока не включает эту группу.
