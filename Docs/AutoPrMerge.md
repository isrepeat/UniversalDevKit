# AutoPrMerge

AutoPrMerge.bat в корне репозитория запускает push → PR → merge → пересоздание рабочей ветки. Нужны Git, GitHub CLI и выполненный gh auth login. Незакоммиченные изменения отклоняются; коммиты автоматически не создаются.

```cmd
AutoPrMerge.bat -Head Last -Base master -Title "Update UniversalDevKit" -NewBranch Last
```

Без аргументов значения запрашиваются интерактивно. Пустой заголовок определяется списком изменённых файлов, пустая NewBranch означает исходную ветку. Обёртка работает из любого каталога и делает паузу с сохранением кода завершения.

Открытый PR используется повторно. Merge проверяет опубликованный SHA. Если merge поставлен в очередь, очистка веток не выполняется до подтверждённого MERGED: повторите запуск после merge. Исходные коммиты должны присутствовать в целевой ветке.

После merge исходная remote-ветка удаляется с lease-проверкой SHA, рабочая ветка пересоздаётся от origin/Base и публикуется с upstream. NewBranch не может совпадать с Base; другая существующая NewBranch с собственными коммитами не перезаписывается.

При расхождении local/remote исходной ветки запуск останавливается. ReplaceRemoteHead разрешает force-with-lease после самостоятельной проверки расхождения.

Механизм перенесён из UtilityHelpersLib вместе с MessagingModule. Запуск меняет remote-ветки и GitHub PR; перенос файлов workflow не запускает.
